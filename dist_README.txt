# 使用说明（免安装版）

> 这个文件夹里的 `LinkHarvest.exe` 可以直接运行，**不需要安装 Python 或任何环境**。

---

## 一、最简单的用法

1. 双击 **`LinkHarvest.exe`**
2. 屏幕上出现一个黑窗口，输入 `1` 后回车
3. 把要抓取的网址粘贴进去，**一行一个**
4. 粘贴完后，另起一行输入 `END` 再回车
5. 等它跑完，结果文件夹会自动打开

抓好的文档在 **`output`** 文件夹里，每次运行会新建一个按时间命名的子文件夹：

| 文件 | 说明 |
| --- | --- |
| `xxx.docx` | Word 文档，带目录，最适合阅读和存档 |
| `xxx.xlsx` | Excel 表格，一行一条，适合筛选整理 |
| `xxx.md` | Markdown 文本，适合导入笔记软件 |
| `failed.md` | 如果有的链接抓取失败，这里会写明是哪条、为什么 |

---

## 二、图形界面（不想用黑窗口的话）

双击 `LinkHarvest.exe` → 输入 `2` → 回车。

稍等几秒，浏览器会自动打开一个操作页面，在那里：

- 粘贴链接
- 点「开始抓取」
- 看进度条
- 点按钮直接下载文档

**用完怎么关**：关掉那个黑窗口即可（浏览器页面会失效）。

---

## 三、常见问题

**Q：双击后一闪就没了？**

说明程序报错了。右键 `LinkHarvest.exe` → 「在终端中打开」，再运行一次，
就能看到具体的错误信息。

**Q：提示找不到浏览器？**

本程序需要用到 Chrome 或 Edge 来渲染网页。
Windows 10/11 一般都自带 Edge，通常不会有这个问题。
如果确实没有，装一个 [Chrome](https://www.google.com/chrome/) 即可。

**Q：某些链接抓不到内容？**

常见的三种情况：

1. **需要登录**的网站（如知乎、小红书）——本程序不登录，抓不到；
2. **有反爬风控**的网站（如 36kr、虎嗅）——可能返回验证页；
3. 页面结构特殊，正文识别不出来。

失败的那些会记录在 `failed.md` 里，写明原因。你可以直接在浏览器里打开看。

**Q：抓取很慢？**

- 链接多的话本来就慢，几十条通常要几分钟；
- 程序对同一个网站会自动放慢速度，这是**故意的**，避免被封 IP；
- 请耐心等待，不要重复双击运行。

**Q：会抓图片吗？**

默认不抓图片，只保存文字内容（标题、正文、时间、链接）。
这样文档体积小、速度快。

**Q：安全吗？会不会上传我的数据？**

不会。所有处理都在你本机完成，不联网上传任何东西
（只有访问你指定的那些网页时会联网）。

## 四、给会用命令行的人

`LinkHarvest.exe` 也支持完整参数，和源码版一致：

```bat
LinkHarvest.exe links.txt -o output -c 6
LinkHarvest.exe links.txt --host-delay 2 --images
LinkHarvest.exe --list-sites
LinkHarvest.exe web
```

在 `LinkHarvest.exe` 所在目录按住 Shift + 右键 → 「在此处打开 PowerShell 窗口」，
就能用这些命令。

完整参数说明见项目主页的 README。
